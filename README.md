# Android-Dev

A collection of Android applications built while learning Android development in Android Studio.

Each app is kept in its own project folder and can be opened independently in Android Studio.

## Tech Stack

- Kotlin
- Android Studio
- Gradle
- Android SDK

## Run a Project

1. Clone this repository.

   ```bash
   git clone https://github.com/SHIVANSH5441/Android-Dev.git
   ```

2. Open the folder for the app you want to run in Android Studio.
3. Wait for Gradle sync to finish.
4. Select an Android emulator or connected device.
5. Click **Run**.
